# About

This repo has labs and other stuff related to reviewing and practicing the network concepts. Most of of the lab tasks are generated by an AI model and solved by me.

## Labs

Practical applications such as building a network in Cisco Packet Tracer.

### Labs description

[SOHO Lab](https://github.com/AbdullKhalq/learning-network-plus/blob/b34d34a8064343e740055830ee1fea896bdb2149/review/soho-with-dns-dchp-http.pkt): a small office LAN where devices received their configuration automatically, communicated across a router, used a remote DNS server, and shared one outside IP address through PAT.  

- IPv4 addressing — assigned addresses to the router interfaces and server.
- Subnetting — used 192.168.10.0/24 for the LAN and 203.0.113.0/24 for the outside network.
- Default gateways — clients used the router to reach other networks.
- DHCP — the router automatically gave PCs their IP address, subnet mask, gateway, and DNS server.
- DHCP exclusions — reserved .1 to .20 so DHCP would not assign them.
- DNS — used a DNS server on another network and saw that routing allows clients to reach it.
- Routing — the router moved traffic between the two different networks.
- NAT inside/outside — marked which router interface belonged to the private LAN and which belonged to the outside network.
- PAT (NAT overload) — allowed several private devices to share the router's single outside IP address.
- ACL for NAT — used a standard ACL to specify which private network should be translated.
- Verification/troubleshooting — used commands such as show ip interface brief, show ip dhcp binding, show ip nat translations, and ping.
